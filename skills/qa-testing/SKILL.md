# 测试工程技能

## 测试策略

### 测试金字塔
```
           /\
          /  \     E2E测试 (少量，快速执行)
         /----\
        /      \   集成测试 (中量)
       /--------\
      /          \  单元测试 (大量，快速)
     /____________\
```

### 测试分层
| 层次 | 覆盖目标 | 数量建议 | 执行时间 |
|------|----------|----------|----------|
| 单元测试 | 函数/类级别 | 100+/模块 | <1s |
| 集成测试 | 模块交互 | 20-50/模块 | <10s |
| E2E测试 | 核心流程 | 10-20/功能 | <60s |

## 测试用例设计

### 等价类划分
1. **有效等价类**：符合需求的输入
2. **无效等价类**：不符合需求的输入

### 边界值分析
- 上边界、刚过边界、下边界、刚过下边界

### 测试用例模板
```markdown
## 测试用例：登录功能

### 前置条件
- 用户已注册
- 网络正常

### 测试数据
- 用户名：test_user
- 密码：Test123456

### 执行步骤
1. 打开登录页面
2. 输入用户名
3. 输入密码
4. 点击登录按钮

### 预期结果
- 登录成功
- 跳转到首页
- 显示用户头像

### 优先级
P0 - 核心路径
```

### 常用测试场景
- **功能测试**：输入验证、按钮点击、流程正确性
- **界面测试**：布局、字体、颜色、响应式
- **性能测试**：加载时间、响应速度、资源占用
- **兼容性测试**：不同设备、系统版本、网络环境
- **安全测试**：SQL注入、XSS、越权访问
- **异常测试**：断网、内存不足、服务器异常

## 自动化测试

### 移动端测试工具
- **Appium**：跨平台UI自动化
- **XCTest**：iOS原生测试
- **Espresso**：Android原生测试
- **Detox**：React Native测试

### 自动化策略
```
优先自动化：
✅ 核心路径回归
✅ 高频功能
✅ 数值计算逻辑
✅ API接口

不建议自动化：
❌ 低频功能
❌ 一次性测试
❌ 复杂UI动画
❌ 易变界面
```

## 性能测试

### 性能指标
| 类型 | 指标 | 标准 |
|------|------|------|
| 启动性能 | 冷启动时间 | <3s |
| 界面性能 | FPS | >30fps |
| 内存占用 | PSS | <200MB |
| 网络性能 | API响应时间 | <500ms |
| 电池 | 功耗 | <5W/h |

### 性能测试方法
1. **基准测试**：建立性能基线
2. **压力测试**：逐步加压找极限
3. **稳定性测试**：长时间运行检测泄漏
4. **对比测试**：优化前后对比

## Bug管理

### Bug等级定义
| 等级 | 定义 | 示例 |
|------|------|------|
| P0 | 致命 | 崩溃、数据丢失、无法继续 |
| P1 | 严重 | 核心功能不可用、严重性能问题 |
| P2 | 一般 | 非核心功能Bug、UI显示异常 |
| P3 | 轻微 | 优化建议、文案错误 |
